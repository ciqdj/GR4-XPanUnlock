GR4-XPanUnlock 為 GR IV 加入 **XPan**，也就是經典 35 mm 全景相機的 65:24 全景畫幅，作為 3:2、4:3、1:1 和 16:9 之外的**第五種長寬比**。它的運作方式與原生比例相同：在取景畫面、對焦、儲存的 JPEG、即時重看、**RAW處理**和**剪裁**中都是如此。相機的其他一切都維持原樣，而且隨時都能還原為官方韌體。

本儲存庫不含任何 RICOH 韌體。官方韌體由您自行從 RICOH 下載，再由隨附的工具在您自己的電腦上，將它轉換成 XPan 版本。

> [!WARNING]
> **非官方工具，風險自負。** 並非由 RICOH IMAGING 製作或認可。安裝修改過的韌體可能導致保固失效。請先閱讀[開始之前](#開始之前)和[風險](#風險)。

  <sub>XPan 的取景畫面。整個畫面始終可見；兩條線之間的部分就是照片。</sub>

在長寬比設定中（選單、ADJ 和 Fn／轉盤快捷操作），**XPan 出現在 16:9 之後**，有自己的「XPan」標籤（每種選單語言皆同）和圖示。快捷操作依序切換 3:2 → 4:3 → 1:1 → 16:9 → XPan。

| 裁切／尺寸 | XPan 影像尺寸 |
| --- | --- |
| 全片幅（28 mm），L | 6192 × 2288 |
| 35 mm 裁切，或尺寸 M | 4944 × 1824 |
| 50 mm 裁切，或尺寸 S | 3504 × 1296 |
| 尺寸 XS | 1920 × 712 |

- **取景畫面**顯示整個畫面，就像旁軸相機的開放式觀景窗。裁切範圍以外的景物亮度減半，每個裁切邊緣各有一條細白線，讓您看到即將進入照片的景物。兩條線之間的一切就是照片的內容。**16:9、4:3 和 1:1** 也以相同方式運作。狀態圖示會保持顯示在變暗區域之上。3:2 不變。
- **對焦**保持在照片之內：對焦框可以放在相機的對焦限制範圍與裁切範圍兩者之內的任何位置，一直到線上為止，但絕不會進入變暗區域（無論用按鈕或觸控）。自動區域AF 涵蓋整個 XPan 帶狀區域。
- **即時重看**以 XPan 畫幅顯示剛拍下的照片。
- **RAW（DNG）**檔案保留完整的感光元件影像，與原生比例完全相同。其裁切資訊標示 XPan 畫幅，因此 RAW 轉換軟體會以 XPan 開啟它們，而您之後仍可放寬裁切範圍。
- 相機內的 **RAW處理**：3:2 的 RAW 可處理成 3:2、4:3、1:1、16:9 或 XPan；16:9 或 XPan 的 RAW 可處理成 16:9 或 XPan。
- **剪裁**（播放時在相機內修剪 JPEG）在 16:9 畫框旁提供 XPan 畫框，從 6192 × 2288 到 1920 × 712。
- 選單中的影像尺寸顯示會顯示 XPan 尺寸。
- 3:2、4:3、1:1 和 16:9 的照片、播放和影片錄製都不變。

## 開始之前

- **相機：** RICOH GR IV（標準彩色機型）。不支援其他機型。
- **您的相機必須已更新至韌體 1.11。** 請在相機設定選單中確認版本。
  - 較舊版本：先以一般方式，用 RICOH 的官方檔案更新至 1.11。
  - 較新版本：**請勿使用本工具。** 本工具只支援 1.11。
- **官方韌體檔案。** 從 RICOH IMAGING 官方 GR IV 支援頁面下載**韌體版本 1.11**。如有需要請解壓縮，直到取得 **`fwdc248b.bin`** 檔案。
- **充飽電的電池。** 韌體更新過程中絕不能斷電。
- **一張可以格式化的 SD 卡。**
- **一台安裝 Python 3.8 或更新版本的電腦。** macOS 和大多數 Linux 系統已內建；在 Windows 上，請從 python.org 安裝。不需要其他任何東西。
- 記下您不想重新設定的自訂設定（C1、C2 等）。

## 製作韌體

在此資料夾中開啟終端機並執行（請使用您儲存官方檔案的路徑）：

```sh
python3 gr4_xpanunlock.py patch ~/Downloads/fwdc248b.bin
```

在 Windows 上：

```bat
py gr4_xpanunlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

工具會先確認您提供的是真正的官方 1.11 檔案，接著產生 XPan 韌體並加以檢查。一切正確時，結尾如下：

```
wrote output/fwdc248b.bin  (SHA-256 aa9ac5dbb05d0e362019b78c678ac322fe9b6786d980cafe1846bf191f739cb0)
```

若有問題（例如韌體版本不同、檔案已被修改過，或下載的檔案損毀），工具會顯示 `refused: …`，且**不寫入任何內容**。

## 安裝到相機

### 1. 複製到 SD 卡

1. **在相機中格式化 SD 卡。**
2. 將 **`output/fwdc248b.bin`** 複製到記憶卡的**最上層**：不要放進資料夾，檔名必須完全保持 `fwdc248b.bin`。

### 2. 更新相機

1. 裝入充飽電的電池和 SD 卡。
2. 依照 RICOH 官方 GR IV 韌體更新說明，從相機設定選單開始韌體更新。
3. **相機會顯示從版本 1.11 更新到版本 1.11。** 這是正常的：XPan 韌體保留原本的版本號碼。請確認更新。

> [!CAUTION]
> 在更新完成且相機重新啟動之前，**請勿關閉相機、打開電池蓋或記憶卡蓋，也不要取出記憶卡**。

### 3. 拍攝

- 將長寬比設為 **XPan**（在 16:9 之後）。
- 韌體版本仍顯示 **1.11**，這是正常的。
- 從記憶卡刪除 `fwdc248b.bin`（或格式化記憶卡），以免不小心再次開始更新。

### 還原官方韌體

> [!IMPORTANT]
> **請先將長寬比設為 XPan 以外的任何比例**，例如 3:2，並在每個使用 XPan 的自訂模式（C1、C2 等）中做同樣的設定。官方韌體沒有 XPan 設定。

接著改用 RICOH 的**官方** `fwdc248b.bin` 重複步驟 1–2。相機同樣會顯示 **1.11 → 1.11**；確認後，相機就恢復原廠狀態。

## 2.0.0 的新功能

- **16:9 回來了。** XPan 現在是額外的比例，而不是取代原有的比例，因此您可以在同一個韌體上拍攝 16:9 和 XPan。
- **兩者都有自己的圖示。** 16:9 再次顯示原本的圖示；XPan 在所有出現的地方都有自己的「XPan」圖示。
- **RAW處理**在 16:9 旁提供 XPan 作為獨立選項。
- **剪裁**（播放時修剪）在 16:9 旁提供 XPan 作為獨立比例。
- **即時重看**以 XPan 畫幅顯示 XPan 照片。
- 記憶卡上較舊的 16:9 照片會再次被辨識為 16:9。

### 從 1.x 更新

從 RICOH 的**官方** `fwdc248b.bin` 製作 2.0.0 檔案，方法與[製作韌體](#製作韌體)完全相同，並以相同方式安裝。不需要先還原官方韌體。工具不接受 1.x 的 XPan 檔案作為輸入，因此請一律從 RICOH 的檔案開始。

更新後，在 1.x 上設為 XPan 的相機會顯示 **16:9**，因為 1.x 是以 XPan 取代 16:9。請再次選擇 **XPan**（若您曾將它儲存在 C1、C2 等之中，也請在那裡重新選擇）。

## 須知

- **相機在少數地方會將 XPan 照片視為 16:9：**
  - XPan RAW 的 RAW處理會從 16:9 開始；請選擇 XPan。
  - 剪裁以外的播放編輯（例如更改尺寸）尚未特別針對 XPan 照片測試。
  - XPan 照片的曝光和白平衡測光涵蓋其周圍的 16:9 區域。實際上差異很小。
- **手動對焦和快拍對焦**保持其固定的對焦區域，該區域可能延伸到變暗區域。這不會影響相機在這些模式下的對焦位置。
- **取景畫面的亮度**是在整個畫面上測量，而不只是裁切範圍，因此帶狀區域以外的天空非常亮或非常暗時，曝光可能與您的預期稍有不同。
- **臉部偵測**尚未特別在 XPan 中測試。
- **GR4-MonoUnlock 和 GR4-XPanUnlock 無法同時安裝。** 兩個工具都從官方韌體開始，而本工具不接受 MonoUnlock 檔案。
- **RICOH 官方更新會移除 XPan。** 它會取代整個韌體。請先設定 XPan 以外的比例（見[還原](#還原官方韌體)）。本工具只支援 1.11；請勿用於其他版本。
- **只適用於標準版 GR IV。** 絕對不要將此檔案安裝到其他機型。
- **送修相機之前**，請先還原官方韌體。

### 檢查韌體檔案

將任何韌體檔案複製到記憶卡之前：

```sh
python3 gr4_xpanunlock.py check path/to/fwdc248b.bin
```

它會告訴您該檔案是官方 1.11、本工具製作的 XPan 版本（2.0.0 或較舊的 1.x），還是其他檔案。

## 風險

- 相機無法分辨良好的韌體檔案和損毀的檔案。只將工具寫入的檔案（或經 `check` 確認的檔案）複製到記憶卡。
- 若更新中斷，或韌體檔案無法啟動，相機可能無法再進入更新功能，屆時就需要 RICOH 維修。測試中沒有發生過這種情況，但無法排除。
- 在仍選擇 XPan 的狀態下還原官方韌體，尚未經過測試。請先設定其他比例。
- 相機本身的校正資料不會被更動。

## 運作原理

GR IV 的選單、影像處理、取景畫面、RAW處理和剪裁，全都是圍繞四種長寬比建構的。本工具加入 XPan 作為第五種，相機將它視為 16:9 的近親。凡是決定照片形狀的地方（影像尺寸、RAW 裁切、預覽、即時重看、對焦限制、取景畫面標記、剪裁畫框），XPan 都有自己的數值，其他比例則完全維持原樣。
