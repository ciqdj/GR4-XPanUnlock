GR4-XPanUnlock 把 **XPan**（经典 35 mm 全景相机的 65:24 全景画幅）作为 **第五种长宽比** 加入 GR IV，与 3:2、4:3、1:1 和 16:9 并列。它的表现与原生比例一样：在实时取景、对焦、保存的 JPEG、即时重看、**RAW处理** 和 **剪裁** 中都是如此。相机上的其他一切都保持原样，你可以随时恢复官方固件。

本仓库不包含任何 RICOH 固件。官方固件由你自己从 RICOH 下载，附带的工具会在你自己的电脑上把它转换成 XPan 版本。

> [!WARNING]
> **非官方，风险自负。** 并非由 RICOH IMAGING 制作或认可。
> 安装修改过的固件可能导致失去保修。请先阅读[开始之前](#开始之前)和[风险](#风险)。

## 安装后的效果

<p align="center">
  <img src="assets/live-view.svg" width="720" alt="选择 XPan 时的实时取景：黄昏海景的整个 3:2 画面都可见；宽阔的 65:24 区域上下方的亮度减半，每条区域边缘各有一条细白线，对焦框位于区域内的一处岬角上">
  <br>
  <sub>XPan 下的实时取景。整个画面始终可见；两条线之间的部分就是照片。</sub>
</p>

在长宽比设置中（菜单、ADJ 以及 Fn/拨盘快捷方式），**XPan 出现在 16:9 之后**，带有自己的“XPan”标签（在所有菜单语言中）和图标。快捷方式按 3:2 → 4:3 → 1:1 → 16:9 → XPan 循环切换。

| 裁切 / 尺寸 | XPan 图像尺寸 |
| --- | --- |
| 全画幅（28 mm），L | 6192 × 2288 |
| 35 mm 裁切，或尺寸 M | 4944 × 1824 |
| 50 mm 裁切，或尺寸 S | 3504 × 1296 |
| 尺寸 XS | 1920 × 712 |

- **实时取景** 显示整个画面，就像旁轴相机的开放式取景器。裁切范围以外的景物亮度减半，每条裁切边缘各有一条细白线，因此你能看到即将进入画面的内容。两条线之间的一切就是照片包含的内容。**16:9、4:3 和 1:1** 的工作方式相同。状态图标保持显示在变暗区域之上。3:2 不变。
- **对焦** 始终在照片之内：对焦框可以放在相机对焦限制范围和裁切范围内的任何位置，一直到线上，但绝不会进入变暗区域（无论用按钮还是触摸）。自动区域AF 覆盖整个 XPan 区域。
- **即时重看** 以 XPan 画幅显示你刚拍的照片。
- **RAW（DNG）** 文件保留完整的传感器图像，与原生比例完全相同。它们的裁切信息标出 XPan 画幅，因此 RAW 转换软件会以 XPan 打开它们，你之后仍可放宽裁切。
- 相机内的 **RAW处理**：3:2 的 RAW 可以处理为 3:2、4:3、1:1、16:9 或 XPan；16:9 或 XPan 的 RAW 可以处理为 16:9 或 XPan。
- **剪裁**（回放时在相机内裁剪 JPEG）在 16:9 画幅旁提供 XPan 画幅，从 6192 × 2288 到 1920 × 712。
- 菜单中的图像尺寸显示 XPan 尺寸。
- 3:2、4:3、1:1 和 16:9 的照片、回放和视频录制均不变。

## 开始之前

- **相机：** RICOH GR IV（标准彩色型号）。不支持其他型号。
- **相机必须已升级到固件 1.11。** 请在相机的设定菜单中查看版本。
  - 较旧版本：先用 RICOH 的官方文件按常规方式更新到 1.11。
  - 较新版本：**不要使用本工具。** 它只支持 1.11。
- **官方固件文件。** 从 RICOH IMAGING 官方的 GR IV 支持页面下载 **固件版本 1.11**。如有需要请解压，直到得到文件 **`fwdc248b.bin`**。
- **充满电的电池。** 固件更新过程中绝不能断电。
- **一张可以格式化的 SD 卡。**
- **一台装有 Python 3.8 或更高版本的电脑。** macOS 和大多数 Linux 系统已经自带；在 Windows 上，请从 python.org 安装。不需要其他任何东西。
- 记下你不想重新设置的自定义设置（C1、C2 等）。

## 制作你的固件

在此文件夹中打开终端并运行（请换成你保存官方文件的路径）：

```sh
python3 gr4_xpanunlock.py patch ~/Downloads/fwdc248b.bin
```

在 Windows 上：

```bat
py gr4_xpanunlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

工具会先确认你提供的是真正的官方 1.11 文件，然后生成 XPan 固件并进行检查。一切正常时，它会这样结束：

```
wrote output/fwdc248b.bin  (SHA-256 aa9ac5dbb05d0e362019b78c678ac322fe9b6786d980cafe1846bf191f739cb0)
```

如果出现问题（例如固件版本不同、文件已被修改过，或下载的文件已损坏），它会显示 `refused: …`，并且 **不写入任何内容**。

## 安装到相机

### 1. 复制到 SD 卡

1. **在相机中格式化 SD 卡。**
2. 把 **`output/fwdc248b.bin`** 复制到存储卡的 **根目录**：不要放进文件夹，文件名必须保持为 `fwdc248b.bin`。

### 2. 更新相机

1. 装入充满电的电池和 SD 卡。
2. 按照 RICOH 官方 GR IV 固件更新说明，从相机的设定菜单启动固件更新。
3. **相机会显示从版本 1.11 更新到版本 1.11。** 这是正常的：XPan 固件保留了版本号。请确认更新。

> [!CAUTION]
> **在更新完成且相机重新启动之前，不要关闭相机、不要打开电池仓盖或存储卡盖，也不要取出存储卡。**

### 3. 拍摄

- 把长宽比设为 **XPan**（在 16:9 之后）。
- 固件版本仍显示 **1.11**。这是正常的。
- 从存储卡中删除 `fwdc248b.bin`（或格式化存储卡），以免意外再次启动更新。

### 恢复官方固件

> [!IMPORTANT]
> **先把长宽比设为 XPan 以外的任意比例**，例如 3:2，并在每个使用 XPan 的自定义模式（C1、C2 等）中同样设置。官方固件没有 XPan 设置。

然后改用 RICOH 的 **官方** `fwdc248b.bin`，重复第 1–2 步。相机同样会显示 **1.11 → 1.11**；确认后，相机即恢复为原厂状态。

## 2.0.0 新功能

- **16:9 回来了。** XPan 现在是一个额外的比例，而不是替代 16:9，因此你可以在同一个固件上拍摄 16:9 和 XPan。
- **两者都有自己的图标。** 16:9 重新显示原来的图标；XPan 在所有出现的地方都有自己的“XPan”图标。
- **RAW处理** 把 XPan 作为单独的选项提供，与 16:9 并列。
- **剪裁**（回放时裁剪）把 XPan 作为单独的比例提供，与 16:9 并列。
- **即时重看** 以 XPan 画幅显示 XPan 照片。
- 存储卡上较早的 16:9 照片重新被识别为 16:9。

### 从 1.x 更新

用 RICOH 的 **官方** `fwdc248b.bin` 制作 2.0.0 文件，方法与[制作你的固件](#制作你的固件)完全相同，并以同样的方式安装。无需先恢复官方固件。工具会拒绝以 1.x 的 XPan 文件作为输入，因此请始终从 RICOH 的文件开始。

更新后，在 1.x 上设为 XPan 的相机会显示 **16:9**，因为 1.x 把 XPan 放在了 16:9 的位置上。请重新选择 **XPan**（如果你把它保存在 C1、C2 等中，也请在那里重新选择）。

## 须知

- **相机在少数地方把 XPan 照片当作 16:9 处理：**
  - 对 XPan RAW 进行 RAW处理时，起始比例为 16:9；请选择 XPan。
  - 除剪裁以外的回放编辑（例如更改尺寸）尚未专门在 XPan 照片上测试。
  - XPan 照片的曝光和白平衡测光覆盖其周围的 16:9 区域。实际差异很小。
- **手动对焦和快拍对焦** 保持其固定的对焦区域，该区域可能延伸到变暗区域上。这不影响相机在这些模式下的对焦位置。
- **实时取景亮度** 是在整个画面上测量的，而不只是在裁切范围内，因此当区域外的天空非常亮或非常暗时，曝光可能与你预期的略有不同。
- **脸部检测** 尚未专门在 XPan 中测试。
- **GR4-MonoUnlock 和 GR4-XPanUnlock 不能同时安装。** 每个工具都从官方固件开始，而本工具会拒绝 MonoUnlock 文件。
- **RICOH 官方更新会移除 XPan。** 它会替换整个固件。请先设置 XPan 以外的比例（见[恢复官方固件](#恢复官方固件)）。本工具只支持 1.11；不要将其用于其他版本。
- **仅适用于标准版 GR IV。** 切勿在其他型号上安装该文件。
- **送修相机之前，** 请恢复官方固件。

### 检查固件文件

将任何固件文件复制到存储卡之前：

```sh
python3 gr4_xpanunlock.py check path/to/fwdc248b.bin
```

它会告诉你该文件是官方 1.11、由本工具制作的 XPan 版本（2.0.0，或较旧的 1.x），还是其他文件。

## 风险

- 相机无法区分完好的固件文件和损坏的文件。只把工具写出的（或经 `check` 确认的）文件复制到存储卡。
- 如果更新被中断，或固件文件无法启动，相机可能无法再进入更新功能，届时就需要 RICOH 维修。测试中没有发生过这种情况，但不能排除。
- 在仍选择 XPan 的情况下恢复官方固件尚未测试过。请先设置其他比例。
- 相机自身的校准数据不会被改动。

## 工作原理

GR IV 的菜单、图像处理、实时取景、RAW处理和剪裁都是围绕四种长宽比构建的。工具把 XPan 作为第五种加入，相机将其视为 16:9 的近亲。凡是决定照片形状的地方（图像尺寸、RAW 裁切、预览、即时重看、对焦限制、实时取景标记、剪裁画幅），XPan 都有自己的数值，其他比例则完全保持原样。
