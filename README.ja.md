GR4-XPanUnlockは、往年の35 mmパノラマカメラの65:24のパノラマフレーム、**XPan**を、3:2、4:3、1:1、16:9に続く**5つ目のアスペクト比**としてGR IVに追加します。ネイティブの比率と同じように働きます。ライブビューでも、ピント合わせでも、保存されるJPEGでも、クイックビューでも、**RAW現像**でも、**トリミング**でも。カメラのそれ以外の部分はすべてそのままで、いつでも公式ファームウェアに戻せます。

このリポジトリにRICOHのファームウェアは含まれていません。公式ファームウェアはご自身でRICOHからダウンロードしてください。同梱のツールが、お使いのコンピューター上で、それをXPan版に作り変えます。

> [!WARNING]
> **非公式です。ご自身の責任でお使いください。** RICOH IMAGINGが作成・承認したものではありません。改変したファームウェアをインストールすると、保証が受けられなくなる場合があります。先に[はじめる前に](#はじめる前に)と[リスク](#リスク)をお読みください。

## 得られるもの

<p align="center">
  <img src="assets/live-view.svg" width="720" alt="XPanを選んだときのライブビュー：夕暮れの海の風景の3:2のフレーム全体が見えている。横長の65:24の帯の上下は明るさが半分に落とされ、帯の上下の端にはそれぞれ細い白い線があり、フォーカス枠は帯の中の岬に置かれている">
  <br>
  <sub>XPanのライブビュー。フレーム全体が見えたままで、線と線の間が写真になります。</sub>
</p>

アスペクト比の設定（メニュー、ADJ、Fn/ダイヤルのショートカット）では、**16:9の後にXPanが表示されます**。独自の「XPan」の表示名（メニューのどの言語でも）とアイコンが付きます。ショートカットでは、3:2 → 4:3 → 1:1 → 16:9 → XPanの順に切り替わります。

| クロップ / 大きさ | XPanの画像サイズ |
| --- | --- |
| フルフレーム（28 mm）、L | 6192 × 2288 |
| 35 mmクロップ、または大きさM | 4944 × 1824 |
| 50 mmクロップ、または大きさS | 3504 × 1296 |
| 大きさXS | 1920 × 712 |

- **ライブビュー**は、レンジファインダーの枠の外まで見えるファインダーのように、フレーム全体を表示します。切り出し範囲の外側は明るさが半分に落とされ、切り出し範囲の各端に細い白い線が引かれるので、これから写真に入ってくるものが見えます。線と線の間にあるものすべてが、写真に写る範囲です。**16:9、4:3、1:1**も同じように動作します。ステータスアイコンは、暗くなった部分の上に重ねて表示されます。3:2は変わりません。
- **フォーカス**は写真の中に収まります。フォーカス枠は、カメラのフォーカスの制限範囲と切り出し範囲の両方の内側なら、線の際までどこにでも置けますが、暗くなった部分には（ボタンでもタッチでも）置けません。オートエリアAFはXPanの帯全体をカバーします。
- **クイックビュー**では、撮ったばかりの写真がXPanのフレームで表示されます。
- **RAW（DNG）**ファイルは、ネイティブの比率と同じく、センサーの画像全体を保持します。その切り出し情報がXPanのフレームを示すので、RAW現像ソフトではXPanで開かれます。あとから切り出し範囲を広げることもできます。
- カメラ内の**RAW現像**：3:2のRAWは3:2、4:3、1:1、16:9、XPanに、16:9またはXPanのRAWは16:9またはXPanに現像できます。
- **トリミング**（再生時にカメラ内でJPEGを切り抜く機能）では、16:9の枠と並んで、6192 × 2288から1920 × 712までのXPanの枠を選べます。
- メニューに表示される画像サイズ（大きさ）は、XPanのサイズになります。
- 3:2、4:3、1:1、16:9の写真、再生、動画撮影は変わりません。

## はじめる前に

- **カメラ：** RICOH GR IV（標準のカラーモデル）。ほかの機種には対応していません。
- **カメラのファームウェアがすでに1.11である必要があります。** バージョンはカメラのセットアップメニューで確認してください。
  - 古いバージョンの場合：まずRICOHの公式ファイルを使い、通常の方法で1.11にアップデートしてください。
  - 新しいバージョンの場合：**このツールは使わないでください。** 対応しているのは1.11だけです。
- **公式ファームウェアファイル。** RICOH IMAGINGの公式GR IVサポートページから、**ファームウェアバージョン1.11**をダウンロードします。必要に応じて展開し、**`fwdc248b.bin`** というファイルを取り出します。
- **満充電のバッテリー。** ファームウェアアップデート中に電源が切れることは絶対に避けてください。
- フォーマットしてもよい**SDカード**。
- **Python 3.8以降が入ったコンピューター。** macOSとほとんどのLinuxシステムには、すでに入っています。Windowsでは、python.orgからインストールしてください。ほかには何も必要ありません。
- 設定し直したくないカスタム設定（C1、C2など）は控えておいてください。

## ファームウェアを作る

このフォルダでターミナルを開き、次を実行します（公式ファイルを保存した場所のパスを使ってください）。

```sh
python3 gr4_xpanunlock.py patch ~/Downloads/fwdc248b.bin
```

Windowsでは：

```bat
py gr4_xpanunlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

ツールはまず、渡されたファイルが本物の公式1.11ファイルであることを確認し、それからXPanファームウェアを作成して確認します。すべて正しければ、最後は次のようになります。

```
wrote output/fwdc248b.bin  (SHA-256 aa9ac5dbb05d0e362019b78c678ac322fe9b6786d980cafe1846bf191f739cb0)
```

問題がある場合（たとえばファームウェアのバージョンが違う、すでに改変されたファイルである、ダウンロードしたファイルが壊れているなど）、ツールは`refused: …`と表示し、**何も書き出しません**。

## カメラに入れる

### 1. SDカードにコピーする

1. **カメラでSDカードをフォーマットします。**
2. **`output/fwdc248b.bin`** をカードの**最上位**にコピーします。フォルダの中には入れず、名前は`fwdc248b.bin`のまま変えないでください。

### 2. カメラをアップデートする

1. 満充電のバッテリーとSDカードを入れます。
2. RICOHの公式GR IVファームウェアアップデート手順に従い、カメラのセットアップメニューからファームウェアアップデートを開始します。
3. **カメラには、バージョン1.11からバージョン1.11へのアップデートと表示されます。** これは想定どおりです。XPanファームウェアはバージョン番号をそのまま保ちます。アップデートを確定してください。

> [!CAUTION]
> アップデートが完了してカメラが再起動するまで、**カメラの電源を切ったり、バッテリーカバーやカードカバーを開けたり、カードを取り出したりしないでください。**

### 3. 撮影する

- アスペクト比を**XPan**（16:9の後）に設定します。
- ファームウェアのバージョンは**1.11**のままです。これは正常です。
- 誤ってアップデートが再び始まらないように、カードから`fwdc248b.bin`を削除してください（またはカードをフォーマットします）。

### 公式ファームウェアに戻す

> [!IMPORTANT]
> **まず、アスペクト比をXPan以外に設定してください。** たとえば3:2にし、XPanを使っているすべてのカスタムモード（C1、C2など）でも同じようにします。公式ファームウェアにはXPanの設定がありません。

その後、代わりにRICOHの**公式** `fwdc248b.bin` を使って、手順1〜2を繰り返します。カメラにはまた**1.11 → 1.11**と表示されます。確定すれば、カメラは元の状態に戻ります。

## 2.0.0の新機能

- **16:9が戻りました。** XPanは置き換えではなく追加の比率になったので、同じファームウェアで16:9とXPanの両方を撮影できます。
- **どちらにも独自のアイコン。** 16:9には元のアイコンが再び表示され、XPanには、表示されるすべての場所で独自の「XPan」アイコンが付きます。
- **RAW現像**では、16:9と並んで、XPanを独立した選択肢として選べます。
- **トリミング**（再生時の切り抜き）では、16:9と並んで、XPanを独立した比率として選べます。
- **クイックビュー**では、XPanの写真がXPanのフレームで表示されます。
- カードにある以前の16:9の写真は、再び16:9として認識されます。

### 1.xからのアップデート

2.0.0のファイルは、[ファームウェアを作る](#ファームウェアを作る)とまったく同じように、RICOHの**公式** `fwdc248b.bin` から作り、同じ方法でインストールします。先に公式ファームウェアに戻す必要はありません。ツールは1.xのXPanファイルを入力として受け付けないので、必ずRICOHのファイルから始めてください。

アップデート後、1.xでXPanに設定していたカメラには**16:9**と表示されます。1.xではXPanが16:9の代わりに入っていたためです。もう一度**XPan**を選んでください（C1、C2などに保存していた場合は、そちらでも）。

## 知っておきたいこと

- **カメラはいくつかの場面で、XPanの写真を16:9として扱います：**
  - XPanのRAWのRAW現像は16:9から始まります。XPanを選んでください。
  - トリミング以外の再生時の編集（たとえばリサイズ）は、XPanの写真では特にテストしていません。
  - XPanの写真の露出とホワイトバランスの測光は、その周りの16:9の範囲が対象になります。実際には差はわずかです。
- **MFとスナップのフォーカス**では、固定のフォーカスエリアがそのまま使われ、暗くなった部分にかかることがあります。これらのモードでカメラがピントを合わせる位置には影響しません。
- **ライブビューの明るさ**は、切り出し範囲だけでなくフレーム全体で測られます。そのため、帯の外の空がとても明るい場合や暗い場合は、露出が予想とわずかに違うことがあります。
- **顔/瞳検出**は、XPanでは特にテストしていません。
- **GR4-MonoUnlockとGR4-XPanUnlockは同時にインストールできません。** どちらのツールも公式ファームウェアから作るもので、このツールはMonoUnlockのファイルを受け付けません。
- **RICOHの公式アップデートで、XPanは消えます。** ファームウェア全体が置き換わるためです。先にXPan以外の比率に設定してください（[公式ファームウェアに戻す](#公式ファームウェアに戻す)を参照）。このツールが対応しているのは1.11だけです。ほかのバージョンでは使わないでください。
- **標準のGR IV専用です。** ほかの機種には絶対にインストールしないでください。
- **カメラを修理に出す前に**、公式ファームウェアに戻してください。

### ファームウェアファイルを確認

ファームウェアファイルをカードにコピーする前に確認してください。

```sh
python3 gr4_xpanunlock.py check path/to/fwdc248b.bin
```

ファイルが公式の1.11か、このツールで作ったXPan版（2.0.0、または以前の1.x）か、それ以外かがわかります。

## リスク

- カメラは、正常なファームウェアファイルと壊れたファイルを見分けられません。カードにコピーするのは、このツールが書き出した（または`check`で確認した）ファイルだけにしてください。
- アップデートが中断された場合や、ファームウェアファイルが起動できない場合、カメラがアップデート機能に再びたどり着けなくなり、RICOHの修理が必要になる可能性があります。テストではこのようなことは起きていませんが、可能性は否定できません。
- XPanを選んだまま公式ファームウェアに戻すことは、テストしていません。先にほかの比率に設定してください。
- カメラ固有のキャリブレーションデータには手を加えません。

## 仕組み

GR IVのメニュー、画像処理、ライブビュー、RAW現像、トリミングは、すべて4つのアスペクト比を前提に作られています。ツールはXPanを5つ目として追加し、カメラはそれを16:9の近い仲間として扱います。写真の形が決まるところ（画像サイズ、RAWの切り出し、プレビュー、クイックビュー、フォーカスの制限範囲、ライブビューの線、トリミングの枠）ではどこでも、XPanが独自の値を持ち、ほかの比率はまったくそのままです。
